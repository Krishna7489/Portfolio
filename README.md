# Krishna Garg — Portfolio

A modern, responsive developer portfolio built with plain HTML, CSS and JavaScript.

## Run
Open `index.html` directly in a browser, or use VS Code Live Server.

## Before publishing
1. Replace `your.email@example.com` with your real email.
2. Replace the LinkedIn placeholder with your LinkedIn profile URL.
3. Add more projects inside the Projects section.
4. Update education/skills if needed.

## Included
- Responsive layout
- Dark modern UI
- Smooth scrolling
- Scroll reveal animations
- Navbar blur on scroll
- Scroll progress bar
- Mobile menu
- Hover transitions
- Project showcase
